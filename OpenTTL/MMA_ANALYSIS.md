# MMA（Modality Mirror Alignment）失效分析

> 结论：MMA 在 MMStar/Qwen3.5-2B 上无任何效果。失效源于算法设计本身——
> 目标错位、原生模型无可修的模态间隙、指标不含任务信息、干预通道结构性弱，
> 四者叠加。已排除实现 bug（注入通路经 η 增大实验验证正常工作）。

- 涉及代码：`src/openttl/strategies/mma.py`
- 评测脚本：`evaluations/run_mmstar.py`
- 模型：Qwen3.5-2B（L=24，d=2048，l\*=16）
- 生产配置：K=5, η=0.1, λ=0.01

---

## 1. 现象

MMStar 全量 1500 题（`outputs/mmstar_mma/`，2026-09-02）：

| 运行 | accuracy | correct/total |
|---|---|---|
| baseline | 0.6167 | 925/1500 |
| MMA | 0.6147 | 922/1500 |

Δ = -0.2%（3 题），纯噪声。

## 2. 诊断实验：干预实际施加了多少（`diagnose_mma.py`，3 个样本结果一致）

### 2.1 δ 的量级

| 量 | 数值 |
|---|---|
| 第 16 层 ‖V_j‖ 均值 | ≈ 12 |
| 初始梯度范数 | ≈ 3.4e-2 |
| mean-cos 上界 ‖t̄‖ | ≈ 0.47（起点 0.17） |

| η | mean-cos 变化 | ‖δ‖ | ‖δ‖/‖V‖ |
|---|---|---|---|
| 0.1（生产配置） | 0.1782 → 0.1787 | 1.7e-2 | **0.14%** |
| 1 | → 0.1828 | 1.6e-1 | 1.4% |
| 10 | → 0.2106 | 1.1 | 9% |
| 100 | → 0.073（震荡恶化） | 7.0 | 58% |

### 2.2 注入对最终 logits 的影响

| 配置 | max Δlogit | KL | top-1 |
|---|---|---|---|
| η=0.1 | 0.16 | ~1e-5 | 不变 |
| η=100 | 1.7 | ~1e-3 | 仍不变 |

bf16 注入后元素级实际改变量 mean≈1e-4（vs ‖V‖≈12）。

**读法**：生产配置下 δ 仅占隐状态量级的 0.14%，贪心解码下不可能翻动任何 token；
即使把 δ 加到 ‖V‖ 的 58%（目标函数已震荡恶化），logits 依然几乎不动。
注入通路本身正常工作（η=100 时 logits 确实变化），排除实现错误。

## 3. 相关性实验：目标函数值与答题正确零相关（`corr_mma.py`，400 样本）

复用 baseline 逐题对错，仅前向计算各样本 mean-cos（l\*=16）：

| 统计量 | 数值 |
|---|---|
| 答对组 mean-cos | 0.1697 ± 0.0145（n=255） |
| 答错组 mean-cos | 0.1690 ± 0.0125（n=145） |
| 点二列相关 r | +0.024（p=0.63） |
| Spearman ρ | ≈0（p=0.97） |
| Mann-Whitney AUC | **0.499**（纯随机水平） |

剔除未抽取出答案的样本后结论不变；按 category 分组亦无显著相关。
数据：`outputs/mmstar_mma/mean_cos_corr.csv`。

**含义**：MMA 目标函数所度量的量与"模型能否答对该题"没有信息关联。
优化器在合理步长下能把 mean-cos 推到的范围（≈0.21）完全落在自然变异带
（0.13~0.22）内，而该带内看不到任何正确率梯度。

## 4. 失效原因的深入分析

### 4.1 任务层：MMStar 的瓶颈根本不在"模态对不对齐"

MMStar 的错误来源，看 baseline 的实际表现就知道：

- **感知/推理错误**：数错物体、看错空间关系、推理链出错——这些信息在 16 层
  交互后早已进入文本侧，错在"提取和推理"环节；
- **格式错误**：80/1500 题是模型写了一大段推理但没按格式给答案（unextracted），
  纯指令遵循问题；
- 而 MMA 优化的是"视觉 token 与文本 token 的全局方向接近度"——跟上面任何一种
  错误都不在一条因果链上。

更关键的是，答这类题模型需要的是**区分**：从 ~192 个视觉 token 里挑出与问题
相关的那几个（"左边那辆灰色自行车"）。而 mean-cos 是对所有 token 对做**无差别
的全局拉拢**——优化方向恰恰与任务需求相反。所以它不是"弱效"，是目标错位
（misaligned objective）。

### 4.2 模型层：原生 MLLM 没有"模态间隙"可修

Modality gap 是 CLIP 那种双塔独立编码的现象——两个编码器各编各的，表示空间
天然分离，对齐才有意义。Qwen3.5-VL 里视觉 token 从第 0 层起就在 LM 栈内与文本
token 互相 attention，且端到端训练过，到 l\*=16 时跨模态早已充分混合。

数据也印证了这一点：400 个样本的 mean-cos 挤在 **0.17 ± 0.014** 的窄带里
（变异系数仅 8%）。指标已经饱和——既没有"间隙"可填，样本间的动态范围也小到
不可能区分难易题。用一个接近常数的量去预测对错，AUC=0.499 是必然结果。

### 4.3 指标层：全对平均把仅剩的信息也压没了

192×127 个 token 对压成一个标量，而且这个标量只由两个质心决定；T 里一大半是
system prompt、模板和特殊 token（`<|vision_start|>` 等），所以文本质心基本是
**固定模板方向**。样本间 mean-cos 的变异主要由"图像整体风格带来的共性方向"
驱动，而不是题目难度。它度量的东西从源头上就与"答对与否"无关。

### 4.4 机制层：目标与通道的结构性缺陷

**量级错配。** 损失定义在归一化（余弦）空间，δ 作用在原始隐状态空间，梯度被
1/‖V_j‖ 缩放。η∈[0.05, 0.2] 的建议值隐含假设隐状态 O(1)，实际 O(10+)，
δ 因此小了两个数量级（见 2.1）。

**目标退化为质心匹配。** 全对平均余弦有恒等式
`mean_ij cos(T̂_i, V̂'_j) = t̄ᵀ·m(δ)`（t̄、m 为文本/视觉归一化向量的均值），
损失只依赖两个**一阶质心**，token 级判别结构、各向异性完全不受影响——不是
分布匹配。且其全局最优是退化的：δ 主导后所有视觉 token 坍缩到 t̄ 方向
（mean-cos→‖t̄‖≈0.47），即完美优化 = 视觉信息丢失；λ 正则只是在阻止这个坏解。

**干预通道结构性弱。** 所有视觉 token 加同一个 δ：

- 视觉 key 的 logit 全部平移同一常数 q·W_kδ，softmax 对常数平移不变
  → **视觉 token 之间的相对注意力分布严格不变**；
- value 路径的输出变化 = (Σα)·W_vδ，一个与图像内容无关的常量向量；
- 只在 l\* 一层注入一次，后续 8 层 RMSNorm + 残差流进一步稀释。

这解释了 2.2 中"δ 加到 58% ‖V‖ 仍翻不动 top-1"的现象：通道本身几乎不传信号。

## 5. 结论

MMA 的失效不是超参或实现问题，而是四层原因叠加的必然结果：

1. 任务层：MMStar 的瓶颈在感知/推理/格式，全局模态拉拢与答题不在一条因果链上，
   且任务需要的是 token 级区分而非全局对齐——目标错位；
2. 模型层：原生端到端 MLLM 在中间层不存在待修的模态间隙，指标已饱和；
3. 指标层：全对平均把目标压成由模板主导的一阶质心标量，与答题正确零相关
   （AUC=0.499，实测）；
4. 机制层：δ 量级与隐状态错配两个数量级，且"所有视觉 token 加同一偏移"的
   干预方式对注意力结构近乎免疫。
